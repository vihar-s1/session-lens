Spike tuning

A session is a spike if cost ≥ this × the baseline P75 cost (default 3.0). Drives both the dashboard panel and the macOS notification.
Baseline = 75th-percentile session cost over the prior N days, excluding today (default 20). P75 stays honest when most sessions are sub-dollar micro-sessions.
A day is a trend spike if tokens ≥ this × median of the prior 7 days (default 2.0).
